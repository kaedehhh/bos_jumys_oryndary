# CareerHub — SQLite негізіндегі жұмыс орындарын іздеу жүйесі

## Жоба туралы
Бұл нұсқа курстық жұмыста бұрын жасалған `vacancies.db` деректер базасын қолданады.
Бағдарлама Python, Tkinter/ttk және sqlite3 кітапханалары арқылы жасалған.
Интерфейс одногруппницалардың курстық жұмысындағы тәсілге ұқсас: деректер кестелерін
көрсету, кестелер арасында ауысу және форма арқылы жаңа өтінім енгізу.

## Маңызды
- Барлық 7 кесте сақталады: `Users`, `Companies`, `Vacancies`, `Skills`,
  `User_Skills`, `Vacancy_Skills`, `Applications`.
- `main.py` ішінде `CREATE TABLE`, `DROP TABLE` жоқ.
- Бастапқы жазбалар өшірілмейді.
- Өтінім жіберілгенде жаңа қолданушы қажет болса `Users` кестесіне,
  ал өтінім `Applications` кестесіне қосылады.
- Қосымша компаниялар, пайдаланушылар, дағдылар, вакансиялар және өтінімдер
  туралы деректерді көрсетеді.

## Іске қосу (PyCharm)
1. ZIP архивін ашыңыз.
2. `careerhub_sqlite_app` бумасын PyCharm арқылы ашыңыз.
3. `main.py` файлын ашыңыз.
4. Python 3 орнатылғанына көз жеткізіңіз.
5. Run батырмасын басыңыз.

`tkinter` Python-ның стандартты кітапханасына кіреді. Қосымша пакет орнату қажет емес.

## GitHub
GitHub-қа бүкіл `careerhub_sqlite_app` бумасын жүктеуге болады.
Бұл жоба — компьютерде іске қосылатын desktop-қосымша. GitHub кодты сақтайды,
бірақ Tkinter терезесін браузерде жарияламайды.

## Деректер базасының орналасуы
`database/vacancies.db`

Егер курстық жұмыстағы өзекті деректер базасы басқа жерде болса, оны осы файлдың
орнына көшіріңіз (алдымен көшірме жасап алыңыз).
